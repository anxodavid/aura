# Instrucciones Rápidas de Ejecución

Para facilitar el uso de AURA (Analizador de Uso, Ritmo y Artificios) sin necesidad de abrir editores de código como Visual Studio Code, se han incorporado dos scripts automáticos en la carpeta principal del proyecto:

## 1. Instalación (`instalar.bat`)
**Solo necesitas ejecutar este archivo la primera vez** que descargues el proyecto o si hay actualizaciones mayores. 
- Haz doble clic sobre `instalar.bat`.
- Verás una ventana negra que descargará automáticamente los requisitos técnicos (tanto para el motor de análisis como para la interfaz).
- Al finalizar, te dirá "Instalacion completada". Presiona cualquier tecla para cerrar.

## 2. Ejecutar la Aplicación (`iniciar.bat`)
**Utiliza este archivo cada vez que quieras usar AURA.**
- Haz doble clic sobre `iniciar.bat`.
- Se abrirá una pequeña ventana en segundo plano que mantendrá el motor de análisis funcionando.
- Acto seguido, **se abrirá automáticamente una pestaña en tu navegador web por defecto** con AURA listo para usarse.
- **Para cerrar la herramienta**: Simplemente cierra la ventana negra (consola) que se ha quedado abierta y la pestaña del navegador.
